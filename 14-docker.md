حتماً. این بخش یکی از پرتکرارترین مباحث آزمون شرکت، DevSecOps، Kubernetes، Docker، CKA، CKAD و مصاحبه‌های امنیت و زیرساخت است. پاسخ‌ها را به صورت کوتاه، مفهومی و قابل حفظ کردن آورده‌ام.
________________________________________
Docker و Kubernetes
۱. Image
تعریف:
الگوی فقط‌خواندنی (Read-Only) که شامل برنامه، کتابخانه‌ها و وابستگی‌ها برای ساخت Container است.
مثال:
•	nginx
•	ubuntu
•	mysql
________________________________________
۲. Container
تعریف:
نمونه در حال اجرای یک Image که برنامه را به‌صورت ایزوله اجرا می‌کند.
ویژگی:
•	سبک
•	سریع
•	قابل حمل
________________________________________
۳. Dockerfile
تعریف:
فایل متنی شامل دستورالعمل‌های ساخت Docker Image.
نمونه دستورات:
•	FROM
•	COPY
•	RUN
•	CMD
•	ENTRYPOINT
________________________________________
۴. Volume
تعریف:
فضای ذخیره‌سازی دائمی برای نگهداری داده‌های Container.
هدف:
جلوگیری از حذف اطلاعات پس از حذف Container.
________________________________________
۵. Network
تعریف:
شبکه‌ای برای ارتباط بین Containerها و دنیای خارج.
انواع:
•	Bridge
•	Host
•	Overlay
•	None
________________________________________
۶. Secret
تعریف:
محل نگهداری اطلاعات حساس.
مثال:
•	Password
•	Token
•	API Key
•	Certificate
________________________________________
۷. ConfigMap
تعریف:
نگهداری تنظیمات غیرحساس برنامه.
مثال:
•	URL
•	Port
•	Environment Variable
________________________________________
Kubernetes
________________________________________
۸. Pod
تعریف:
کوچک‌ترین واحد قابل اجرا در Kubernetes که شامل یک یا چند Container است.
________________________________________
۹. Deployment
تعریف:
شیء Kubernetes برای مدیریت Podها.
وظایف:
•	ایجاد Pod
•	Update
•	Rollback
•	Replica
________________________________________
۱۰. Namespace
تعریف:
بخش‌بندی منطقی منابع داخل Kubernetes Cluster.
هدف:
تفکیک پروژه‌ها و کاربران.
________________________________________
۱۱. RBAC
Role-Based Access Control
تعریف:
مدیریت سطح دسترسی کاربران بر اساس نقش.
اجزا:
•	Role
•	ClusterRole
•	RoleBinding
________________________________________
۱۲. Admission Controller
تعریف:
مکانیزمی که قبل از ایجاد یا تغییر منابع در Kubernetes درخواست‌ها را بررسی و در صورت نیاز تغییر یا رد می‌کند.
کاربرد:
•	اعمال Policy
•	افزایش امنیت
•	جلوگیری از تنظیمات ناامن
________________________________________

🎯 نکات طلایی برای آزمون
•	Image = قالب (Template) فقط‌خواندنی برای ساخت Container.
•	Container = نمونه در حال اجرای Image.
•	Dockerfile = فایل دستورالعمل ساخت Image.
•	Volume = ذخیره‌سازی دائمی داده‌ها.
•	Network = ارتباط بین Containerها و شبکه.
•	Secret = نگهداری اطلاعات حساس مانند Password، Token و Certificate.
•	ConfigMap = نگهداری تنظیمات غیرحساس برنامه.
•	Pod = کوچک‌ترین واحد قابل اجرا در Kubernetes.
•	Deployment = مدیریت ایجاد، به‌روزرسانی، مقیاس‌پذیری و Rollback مربوط به Podها.
•	Namespace = جداسازی منطقی منابع داخل Cluster.
•	RBAC = کنترل دسترسی بر اساس نقش کاربران.
•	Admission Controller = بررسی و اعمال سیاست‌های امنیتی قبل از ایجاد یا تغییر منابع.

🔥 پرتکرارترین سؤال‌های آزمون
تفاوت Image و Container
•	Image = قالب ثابت برای ساخت Container.
•	Container = نسخه در حال اجرای Image.
تفاوت Secret و ConfigMap
•	Secret = اطلاعات حساس (Password، Token، API Key).
•	ConfigMap = تنظیمات غیرحساس (Port، URL، Environment Variable).
Pod چیست؟
کوچک‌ترین واحد اجرایی در Kubernetes که شامل یک یا چند Container است.
RBAC چیست؟
مدل کنترل دسترسی مبتنی بر نقش (Role-Based Access Control) برای مدیریت مجوز کاربران و سرویس‌ها در Kubernetes.
این مباحث از رایج‌ترین سؤالات آزمون‌های شرکت، DevSecOps و مصاحبه‌های Kubernetes هستند و معمولاً به‌صورت مفهومی یا مقایسه‌ای مطرح می‌شوند.
