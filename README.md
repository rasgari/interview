interview


اگر منظورت آزمون ارزیابی فنی شرکت (مرکز مدیریت راهبردی شرکت) برای شرکت‌های امنیتی یا کارشناسان امنیت اطلاعات است، باید بدانی که بانک سؤالات رسمی منتشر نشده است و کسی نمی‌تواند سؤالات واقعی آزمون را در اختیار داشته باشد. اما بر اساس سرفصل‌ها و تجربه داوطلبان، می‌توان گفت معمولاً از مباحث زیر سؤال مطرح می‌شود.

۱۵. سؤالات عملی و سناریومحور
ممکن است از تو بخواهند توضیح دهی:
•	اگر یک سرور هک شود چه مراحلی را انجام می‌دهی؟
•	اگر SQL Injection پیدا کردی، چگونه آن را گزارش می‌کنی؟
•	اگر وب‌سرور 500 Error بدهد، چه مواردی را بررسی می‌کنی؟
•	چگونه یک تست نفوذ قانونی را برنامه‌ریزی می‌کنی؟
•	تفاوت Vulnerability Assessment و Penetration Test چیست؟
